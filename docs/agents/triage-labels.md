# Rótulos de triagem

As skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia cada papel para o texto usado neste repositório (na linha `Status:` de cada issue em `.scratch/`).

| Rótulo em mattpocock/skills | Rótulo neste repositório | Significado                                  |
| --------------------------- | ------------------------ | -------------------------------------------- |
| `needs-triage`              | `needs-triage`           | O mantenedor precisa avaliar a issue         |
| `needs-info`                | `needs-info`             | Aguardando mais informações de quem reportou |
| `ready-for-agent`           | `ready-for-agent`        | Totalmente especificada, pronta para um agente |
| `ready-for-human`           | `ready-for-human`        | Exige implementação humana                   |
| `wontfix`                   | `wontfix`                | Não será feita                               |

Quando uma skill citar um papel (ex.: "aplique o rótulo de pronta para agente"), use o texto correspondente desta tabela.

Edite a coluna "Rótulo neste repositório" se o vocabulário mudar.
